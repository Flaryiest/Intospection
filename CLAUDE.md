## Project Overview

**Intospection** is a personal portfolio website for ericzuo.ca. It has three separate npm projects plus a scripts directory:
- `web/` — Vite + React 19 SPA (the site UI)
- `api/` — Express 5 + Prisma + PostgreSQL backend
- `worker/` — Cloudflare Worker that syncs artifacts and articles from Notion to KV and serves them via REST
- `scripts/` — One-off utilities (Notion sync to local JSON)

## Commands

### Web frontend (`web/`)
```bash
npm run dev       # Dev server at http://localhost:5173
npm run build     # tsc + vite build
npm run lint      # ESLint
npm run preview   # Preview production build
npm run prettier  # Format with Prettier
npm test          # Unit tests (node --test, tests/ directory)
```

### API backend (`api/`)
```bash
npm run dev       # tsx watch mode at http://localhost:3001
npm run build     # prisma generate + tsc
npm run start     # Run compiled JS
npm run prettier  # Format with Prettier
```

### Cloudflare Worker (`worker/`)
```bash
npm run dev       # wrangler dev (local worker)
npm run deploy    # wrangler deploy
```

### Scripts (`scripts/`)
```bash
npm run sync:notion   # Pull artifacts from Notion API → web/src/data/artifacts.json
```
Requires `NOTION_API_KEY` and `NOTION_DATABASE_ID` env vars (via `scripts/.env`).

### Database
```bash
cd api && npx prisma migrate deploy   # Apply migrations
cd api && npx prisma migrate dev      # Create + apply new migration in dev
```

## Architecture

### Frontend (`web/`)

React Router SPA with six routes:
- `/` — Home/intro
- `/artifacts` — Consumed content (books, articles, etc.) with tag filtering and internalization scores
- `/experiences` — Work and life experiences
- `/writing` — Blog index + mailing list signup
- `/writing/:slug` — Individual article (pre-rendered HTML injected via `dangerouslySetInnerHTML`)
- `/resume` — Redirects to a static PDF in `web/public/`

**Path aliases** (configured in `vite.config.ts` and mirrored in `tsconfig.app.json`):
- `@components` → `src/components/`
- `@pages` → `src/pages/`
- `@assets` → `src/assets/`
- `@data` → `src/data/`
- `@hooks` → `src/hooks/`
- `@utils` → `src/utils/`

Artifacts and articles come from Notion. In production builds the frontend fetches them from the Cloudflare Worker (see `src/hooks/content-cache.ts`); in dev it imports local snapshots from `src/data/` (`artifacts.json` is generated by `scripts/sync-notion.ts`, `articles.json` is a checked-in sample). Home and experiences are hardcoded JSX. The only live call to the Express API is the mailing list subscription.

Notable UI components: command palette (Ctrl/Cmd+K), custom cursor canvas.

### Backend (`api/`)

Minimal Express server with all routes in `src/index.ts` (no separate route files). Database schema has a single `MailingList` model (id, unique email, createdAt). Prisma client is imported from `src/generated/prisma/client.js` — the generated client is gitignored, so run `npx prisma generate` (or `npm run build`) after a fresh checkout. CORS allows `http://localhost:5173`, `https://ericzuo.ca`, and `https://www.ericzuo.ca` in all environments.

Endpoints:
- `GET /api/health`
- `POST /api/mailing-list`

### Cloudflare Worker (`worker/`)

Syncs two Notion databases (artifacts and writing) to KV on a cron schedule (every 15 minutes) and serves them via REST:
- `GET /artifacts` — cached artifacts from `ARTIFACTS_KV`
- `GET /articles` — cached article summaries from `WRITING_KV`
- `GET /articles/:slug` — full article including `contentHtml` from `WRITING_KV`
- `POST /sync` — triggers manual Notion sync (unauthenticated)

Article pages are rendered from Notion blocks to HTML at sync time (`src/notion-blocks.ts`); slugs are derived from the article title. Uses two KV namespaces (`ARTIFACTS_KV`, `WRITING_KV`) and three secrets (`NOTION_API_KEY`, `NOTION_DATABASE_ID`, `NOTION_WRITING_DATABASE_ID`). CORS allows the same origins as the API.

### Data flow for content

Notion databases → `worker` (cron every 15 min, writes to Cloudflare KV) → frontend fetches from worker (production builds only; dev uses the local JSON snapshots in `web/src/data/`).
Alternatively for artifacts: Notion → `scripts/sync-notion.ts` → `web/src/data/artifacts.json` (static dev/build-time data).

### Environment

The API requires `api/.env`:
```env
DATABASE_URL="postgresql://USER:PASSWORD@HOST:5432/DB_NAME"
```

The worker requires Cloudflare secrets: `NOTION_API_KEY`, `NOTION_DATABASE_ID`, `NOTION_WRITING_DATABASE_ID`.

The sync script requires `scripts/.env`:
```env
NOTION_API_KEY="..."
NOTION_DATABASE_ID="..."
```
